    👨‍👦 For grown-ups — how to teach with this

    This is a junior version of the solver tools you use: "guess points" is expected value, the fixture map is a difficulty model, the budget rules are constrained optimisation, and the dress-rehearsal histogram is your points-distribution panel. The ideas are identical — only the language is smaller.

    A weekly routine that works

    1. Fixture map first (2 min). Ask: "Which teams have the friendliest games this week?" This trains reading a model's output before looking at any player.

    2. Transfers or picks (5 min). Sort the market by Value and ask why a £5m player can be a smarter buy than a £9m one. That's expected value per unit cost — the core solver idea.

    3. Captain duel (3 min). Frame everything as "out of 10 matches like this one…". It converts expected value from an abstract decimal into counting, which 9-year-olds handle brilliantly.

    4. After the deadline: dress rehearsal. Run 100 simulations, write down the mean, then compare with the real score at the weekend. Ask: "Were we unlucky, or wrong?" — the single most valuable idea in all of this (judge the decision, not the outcome).

    Concepts he'll absorb, in order

    Averages and expected value → value for money (ratios) → probability as long-run counting → variance and distributions → sample size ("one great week proves nothing") → wisdom of the crowd (ownership %) → process vs luck. Each lesson card in "Learn the maths" matches one of these and ends with a question to talk about together.

    Honest notes on the data

    Guess pts is now our own projection model, built like the professional tools (Solio-style) but from free official data, so it can be explained line by line: expected minutes (season minutes per team game × the availability flag), attacking threat (xG and xA per 90, shrunk toward positional priors so two hot games don't create a superstar), clean-sheet chances and saves by fixture difficulty, then blended with FPL's own guess while samples are small. The 3-wk pts column runs the same model for each of the next three fixtures with attack multipliers (easy ×1.25 → very hard ×0.62). Walk him through it once — every ingredient is a lesson: minutes multiply everything, rates need shrinking on small samples, fixtures shift probabilities.

    The My team tab reads his real squad from the FPL API each morning (picks appear for a gameweek once its deadline passes). The "what the maths says" panel deliberately gives clues, not orders — captain check, minutes warnings, bench comparisons, tough runs — so the two of you still make the decision.

    Player list, prices, ownership and "guess points" come from the official FPL API (top 150 most-picked players); fixture difficulty is FPL's official FDR. Early-season guess points are crude — a fun discussion in itself: "Why might the computer's guess be bad so early?" (Small sample!) The site now refreshes its own data every morning: a small scheduled robot (a GitHub Action) fetches the FPL API and updates the page — just open it and it's current.
